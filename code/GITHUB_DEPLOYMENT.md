# Инструкция по загрузке на GitHub и настройке Yandex Cloud

## 1. Загрузка проекта на GitHub

### Шаг 1: Добавление файлов в Git
```bash
cd dog-walks-app
git add .
git commit -m "Initial commit: Dog Walks App with duration tracking"
```

### Шаг 2: Подключение к удалённому репозиторию
```bash
git remote add origin https://github.com/an-pit/dog-walks.git
git branch -M main
git push -u origin main
```

### Шаг 3: Если репозиторий уже существует
Если репозиторий уже создан на GitHub, может потребоваться:
```bash
git pull origin main --allow-unrelated-histories
git push origin main
```

## 2. Уточнение по настройке Yandex Cloud

### Образ загрузочного диска
В интерфейсе Yandex Cloud при создании VM нужно выбрать:

**Рекомендуемые настройки:**
- **Тип образа**: `Публичные образы`
- **Операционная система**: `Ubuntu`
- **Версия**: `Ubuntu 22.04 LTS`
- **Архитектура**: `Intel Ice Lake`

### Пошаговый выбор образа:
1. В разделе "Образ" нажмите "Выбрать"
2. Перейдите на вкладку "Публичные образы"
3. В поиске введите "Ubuntu 22.04"
4. Выберите "Ubuntu 22.04 LTS"
5. Убедитесь, что архитектура "Intel Ice Lake"

### Альтернативные варианты (если Ubuntu 22.04 недоступен):
- Ubuntu 20.04 LTS
- Debian 11
- CentOS 7 (менее предпочтительно для Node.js)

## 3. Обновлённая инструкция для Yandex Cloud

### Создание VM с правильным образом:

1. **Перейдите в Compute Cloud** → "Виртуальные машины"
2. **Нажмите "Создать ВМ"**
3. **Основные настройки:**
   - Имя: `dog-walks-server`
   - Зона доступности: `ru-central1-a`
   - Платформа: Intel Ice Lake

4. **Образ загрузочного диска:**
   - Тип: Публичные образы
   - ОС семейство: Linux
   - ОС: Ubuntu 22.04 LTS
   - Версия: Последняя доступная

5. **Диск:**
   - Тип: SSD
   - Размер: 20 GB

6. **Вычислительные ресурсы:**
   - Платформа: Intel Ice Lake
   - Гарантированная доля vCPU: 100%
   - vCPU: 2
   - RAM: 2 GB

7. **Сетевые настройки:**
   - Публичный адрес: Автоматически
   - Внутренний адрес: Автоматически
   - Группа безопасности: Создать новую или выбрать существующую

8. **Доступ:**
   - Логин: `ubuntu`
   - SSH-ключ: Добавить ваш публичный ключ

## 4. Проверка образа после создания

После создания VM подключитесь и проверьте:
```bash
ssh ubuntu@<IP-адрес>
lsb_release -a  # Должен показать Ubuntu 22.04 LTS
node --version  # Покажет, что Node.js не установлен (нужно установить)
npm --version   # Покажет, что npm не установлен
```

## 5. Если возникли проблемы с образом

Если выбранный образ не работает корректно:

1. **Создайте новый диск из образа:**
   - Compute Cloud → "Диски"
   - Создать диск → Из образа
   - Выберите Ubuntu 22.04 LTS

2. **Создайте VM с этим диском:**
   - При создании VM выберите "Из существующего диска"
   - Выберите созданный диск

## 6. Дополнительные рекомендации

### Для Node.js 18+ лучше всего подходят:
- Ubuntu 22.04 LTS (рекомендуется)
- Ubuntu 20.04 LTS
- Debian 11

### Избегайте:
- CentOS 7 (устаревшие пакеты)
- Windows Server (не подходит для нашего стека)
- Alpine Linux (требует дополнительной настройки)

После успешной настройки VM продолжайте следовать инструкциям из DEPLOYMENT.md
