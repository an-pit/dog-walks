# План разработки приложения "Прогулки с собакой"

## 📋 Требования

### Функциональные требования
- Открытый доступ по одной ссылке, без авторизации
- Календарь на неделю или день
- 3 слота в день: утро, день, вечер
- 4 состояния слота: Андрей / Ира / Оба / Никто
- Статистика прогулок за период
- Экспорт данных в CSV
- Адаптивный дизайн (веб + мобильный)

### Технические требования
- Хостинг на Yandex Cloud
- Простая архитектура, минимальная стоимость

## 🏗️ Архитектура

```
Frontend: React (Vite) - SPA
Backend: Node.js (Express) - REST API
Database: SQLite (файл walks.db)
Hosting: Yandex Cloud Compute Cloud (Ubuntu VM)
Proxy: Nginx (reverse proxy + статика)
```

## 🗄️ Структура данных

### Таблица `walks`
| Поле | Тип | Описание |
|---|---|---|
| `id` | INTEGER PK | авто-инкремент |
| `walk_date` | TEXT | дата в формате `YYYY-MM-DD` |
| `slot` | TEXT | `morning` / `afternoon` / `evening` |
| `person` | TEXT | `andrey` / `ira` / `both` / `none` |
| `updated_at` | TEXT | ISO timestamp последнего изменения |

## 🔌 REST API

| Метод | URL | Описание |
|---|---|---|
| `GET` | `/api/walks?from=&to=` | Получить прогулки за период |
| `PUT` | `/api/walks/:date/:slot` | Установить кто гулял |
| `GET` | `/api/stats?from=&to=` | Статистика за период |
| `GET` | `/api/export?from=&to=` | Скачать CSV |

## 📱 UI/UX

### Экраны приложения
1. **Недельный вид** - таблица 7×3 (дни × слоты)
2. **Дневной вид** - крупные карточки слотов
3. **Статистика** - счётчики + таблица + экспорт
